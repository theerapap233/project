# อีเมลสรุปผู้สมัครทุนรายวัน (Google Apps Script)

## ภาพรวม
- หน้าเว็บ (แอดมิน > แท็บ "แจ้งเตือนอีเมล") ใช้ตั้ง เปิด/ปิด, เวลาส่ง, อีเมลผู้รับ และกดส่งอีเมลทดสอบ
- ค่าเหล่านี้เก็บในตาราง `email_digest_settings` ใน Supabase
- Apps Script ทำงานทุก 10 นาที อ่านค่าจาก Supabase ถ้าถึงเวลาและมีผู้สมัครใหม่ จะส่งอีเมลจาก Gmail ของบัญชีที่สร้างสคริปต์ แล้วเขียนผลกลับไปให้หน้าเว็บแสดง

## ขั้นที่ 1: สร้างตารางใน Supabase
Supabase Dashboard > SQL Editor > วางไฟล์ `supabase/email_digest_settings.sql` ทั้งไฟล์ > Run
ผลลัพธ์ด้านล่างต้องเห็น 1 แถว (`enabled = false`, `send_time = 18:00`)

## ขั้นที่ 2: วางโค้ด
1. ใน Apps Script ตั้งชื่อโปรเจกต์ (กดที่ "โครงการไม่มีชื่อ") เช่น `อีเมลสรุปผู้สมัครทุน`
2. เปิดไฟล์ `รหัส.gs` ลบโค้ดเดิมทั้งหมด
3. วางโค้ดจากไฟล์ `apps-script/Code.gs` ทั้งไฟล์ > กด Ctrl+S

## ขั้นที่ 3: ตั้งค่าโปรเจกต์ (ไอคอนเฟือง ⚙ "การตั้งค่าโปรเจ็กต์")
1. เขตเวลา: ติ๊ก "แสดงไฟล์ Manifest appsscript.json" ก็ได้ แต่ที่สำคัญคือช่อง **เขตเวลา** ให้เลือก `(GMT+07:00) Bangkok`
2. เลื่อนลงไปที่ **พร็อพเพอร์ตี้ของสคริปต์** > เพิ่มพร็อพเพอร์ตี้ของสคริปต์

| พร็อพเพอร์ตี้ | ค่า |
|---|---|
| `SUPABASE_URL` | ค่า `VITE_SUPABASE_URL` ในไฟล์ `.env` เช่น `https://xxxx.supabase.co` |
| `SUPABASE_KEY` | ค่า `VITE_SUPABASE_ANON_KEY` ในไฟล์ `.env` |
| `SITE_URL` | (ไม่บังคับ) ลิงก์เว็บ เช่น `https://xxx.vercel.app` จะเป็นปุ่มในอีเมล |

> ห้ามใส่ service_role key เด็ดขาด ใช้ anon key ตัวเดียวกับหน้าเว็บเท่านั้น

3. กด "บันทึกพร็อพเพอร์ตี้ของสคริปต์"

## ขั้นที่ 4: ทดสอบและให้สิทธิ์
1. กลับไปหน้าโค้ด (ไอคอน < >)
2. ช่องเลือกฟังก์ชันข้างปุ่ม "แก้ปัญหา" เลือก **testConnection** > กด **เรียกใช้**
3. Google ขอสิทธิ์: กด "ตรวจสอบสิทธิ์" > เลือกบัญชี > ถ้าขึ้น "Google ยังไม่ได้ยืนยันแอปนี้" กด **ขั้นสูง** > **ไปที่ (ชื่อโปรเจกต์) (ไม่ปลอดภัย)** > **อนุญาต**
   (เป็นเรื่องปกติของสคริปต์ที่เราเขียนเอง สิทธิ์ที่ขอคือ ส่งอีเมล, เชื่อมต่อภายนอก, ตั้งเวลาทำงาน)
4. ดูที่ "บันทึกการดำเนินการ" ต้องเห็น `เชื่อมต่อ Supabase สำเร็จ`

## ขั้นที่ 5: เปิดการทำงานอัตโนมัติ
เลือกฟังก์ชัน **setupTrigger** > กด **เรียกใช้** (ครั้งเดียวพอ)
เช็กได้ที่ไอคอนนาฬิกา ⏰ "ทริกเกอร์" ต้องเห็น `checkAndSend` ทุก 10 นาที

## ขั้นที่ 6: ตั้งค่าจากหน้าเว็บ
1. เข้าเว็บ > ล็อกอินเจ้าหน้าที่ > แท็บ **แจ้งเตือนอีเมล**
2. ใส่อีเมลผู้รับ, เลือกเวลา, ติ๊ก "เปิดการส่งอีเมลอัตโนมัติ" > **บันทึกการตั้งค่า**
3. กด **ส่งอีเมลทดสอบ** > รอไม่เกิน 10 นาที > เช็กกล่องจดหมาย (รวม Spam)
4. ภายใน 10 นาที การ์ดสถานะต้องขึ้น "ทำงานปกติ"

## แก้ปัญหา
| อาการ | วิธีแก้ |
|---|---|
| หน้าเว็บขึ้น "ยังไม่ได้สร้างตารางตั้งค่าอีเมล" | ทำขั้นที่ 1 |
| testConnection ขึ้น "ยังไม่ได้ตั้ง SUPABASE_URL..." | ทำขั้นที่ 3 ข้อ 2 |
| Supabase ตอบกลับ 401 | SUPABASE_KEY ผิด คัดลอกใหม่จาก .env |
| Supabase ตอบกลับ 404 | ยังไม่ได้รัน SQL หรือ SUPABASE_URL ผิด |
| หน้าเว็บขึ้น "Apps Script ไม่ได้ทำงานมา ... นาที" | ทริกเกอร์หาย/ถูกปิด รัน setupTrigger ใหม่ และดูหน้า "การดำเนินการ" (ไอคอน ≡▶) ว่ามี error อะไร |
| ส่งแล้วไม่เห็นอีเมล | ดูโฟลเดอร์ Spam, หรือดูหน้า "การดำเนินการ" |

## ข้อจำกัด
- Gmail ฟรีส่งได้ประมาณ 100 ผู้รับต่อวัน
- ส่งจริงช้ากว่าเวลาที่ตั้งได้ไม่เกินประมาณ 10 นาที
- หยุดการทำงานทั้งหมด: เลือกฟังก์ชัน `removeTrigger` > เรียกใช้
